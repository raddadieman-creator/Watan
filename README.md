# وَطَن | WATAN

**المملكة كما لم تكتشفها من قبل** — منصة معرفية تفاعلية عن المملكة العربية السعودية، مبنية بـ Next.js وقابلة للنشر على Vercel.

**تقديم:** ديما فهد الردادي — مدرسة الموهوبين التقنية (بنات)

[![النشر على Vercel](https://vercel.com/button)](https://vercel.com/new/import?s=https%3A%2F%2Fgithub.com%2Fraddadieman-creator%2FWatan)

## ما يعمل في هذه النسخة (المرحلتان الأولى والثانية)

| الجزء | الحالة |
|---|---|
| الصفحة الرئيسية بخريطة تفاعلية للمناطق الـ13 | يعمل: تمرير، لمس، نقر، لوحة مفاتيح، تكبير وتصغير وإعادة ضبط، Esc للرجوع |
| طبقات الخريطة | مقار الإمارات، أسماء المناطق، السكان (تعداد 2022) مع وسيلة إيضاح |
| صفحة لكل منطقة (13 صفحة) | بيانات موثقة لكل المناطق؛ محتوى مفصل للرياض والمدينة المنورة وعسير |
| التراث في قوائم اليونسكو | 8 مواقع تراث عالمي و18 عنصر تراث غير مادي بروابطها الرسمية |
| المملكة بالأرقام | رسم للمناطق حسب السكان/المساحة/الكثافة، ومقارنة بين منطقتين |
| البحث الموحد | فوري في الشريط العلوي + صفحة نتائج؛ يتسامح مع الهمزات والتاء المربوطة و«ال» |
| المصادر | إحالة بجانب كل معلومة، و«المصادر والمراجع — آخر تحديث» أسفل كل صفحة |
| فحص البيانات | `scripts/validate-data.mjs` يعمل تلقائيًا قبل كل بناء ويوقفه عند أي خلل |

الأقسام غير المبنية بعد (التاريخ، دولتنا، الطبيعة، التعليم، التحول الرقمي، رؤية 2030، المختبر، «دليل»، لوحة الإدارة، النسخة الإنجليزية، وضع العرض) **لا تظهر في القائمة** حتى لا تكون هناك روابط شكلية. قائمتها في صفحة «عن وطن».

## التشغيل المحلي

المتطلبات: Node.js 20.9 أو أحدث.

```bash
npm install
npm run dev          # بيئة التطوير على http://localhost:3000
npm run build        # بناء الإنتاج (يشغّل فحص البيانات أولًا)
npm start            # تشغيل نسخة الإنتاج المبنية
```

لا يحتاج المشروع أي مفتاح أو خدمة خارجية في هذه المرحلة. الخطوط مثبتة من npm (`@fontsource`) ولا تُجلب من الإنترنت وقت البناء، والخريطة SVG تُحسب مساراتها وقت البناء دون خادم خرائط.

## الهوية البصرية

- **الخطوط:** «أميري» (نسخ) للعناوين، و«المراعي» للنصوص والأرقام والواجهة.
- **الألوان:** هوية مشرقة: فيروزي البحر `#1DB4C8`، والأزرق `#1E6F86`، والبرتقالي الزعفراني `#F28C38`، والمرجاني `#E5534B`، والنعناعي `#23A887`، على خلفية عاجية دافئة `#FFFBF4`، مع لون حيوي مميز لكل منطقة في `data/regions.json`.
- **الأطلس:** شروق دافئ خلف العنوان وبحر فيروزي، والمملكة صفيحة بسماكة وظل وكل منطقة بلونها، وأنماط كارتوغرافية للصحارى والجبال والسهول من بيانات Natural Earth، ورفع المنطقة عند المرور أو الاختيار.
- **الزخرفة:** حافة «الشُّرَف» النجدية بين اللوحات، وبطاقات بيضاء بشريط لوني متدرج.
- **الصور:** لم تُدرج صور فوتوغرافية بعد، لأن التحقق من تراخيصها لم يكن متاحًا من بيئة البناء. تُضاف من مصادر مرخصة مع اسم المصوّر والرخصة.

## النشر على GitHub ثم Vercel — خطوة بخطوة

### أولًا: رفع المشروع إلى GitHub

1. ادخلي إلى github.com واضغطي **New repository**.
2. الاسم المقترح: `watan`. اختاري Public أو Private، **ولا** تضيفي README أو .gitignore من GitHub (موجودان في المشروع).
3. اضغطي **Create repository**.
4. من مجلد المشروع على جهازك:

```bash
git init
git add .
git commit -m "وطن: المرحلة الأولى والثانية"
git branch -M main
git remote add origin https://github.com/<اسم-المستخدم>/watan.git
git push -u origin main
```

> مجلد `node_modules` و`.next` وملفات `.env` الحقيقية مستبعدة عبر `.gitignore` ولن تُرفع.

### ثانيًا: ربط المستودع بـ Vercel

1. ادخلي إلى vercel.com وسجّلي الدخول بحساب GitHub.
2. اضغطي **Add New… → Project**.
3. اختاري المستودع `watan` واضغطي **Import**. إن لم يظهر، اضغطي **Adjust GitHub App Permissions** وامنحي Vercel صلاحية الوصول إليه.
4. سيتعرف Vercel على Next.js تلقائيًا. اتركي الإعدادات كما هي:
   - Framework Preset: **Next.js**
   - Build Command: `npm run build`
   - Output Directory: (الافتراضي)
   - Install Command: `npm install`
5. **Environment Variables** (اختياري): أضيفي `NEXT_PUBLIC_SITE_URL` بقيمة رابط المنصة النهائي إذا ربطتِ نطاقًا خاصًا، مثل `https://watan.example`. إن تركتِه، يستخدم المشروع رابط Vercel تلقائيًا.
6. اضغطي **Deploy** وانتظري حتى تظهر رسالة النجاح ورابط المنصة.

### ثالثًا: التحقق بعد النشر

افتحي الرابط وجرّبي:

- [ ] تمرير المؤشر على الخريطة يُظهر اسم المنطقة ومقرها.
- [ ] النقر على أي منطقة من الـ13 يقرّبها ويُظهر ملخصها، و«افتح صفحة …» ينقل إلى صفحتها.
- [ ] على الهاتف: لمس المنطقة يعمل، والقائمة تُفتح من زر القائمة.
- [ ] البحث عن «المدينه» أو «الاحساء» يعطي نتائج صحيحة.
- [ ] `/sitemap.xml` و`/robots.txt` يعملان.

### رابعًا: التحديثات اللاحقة

كل `git push` إلى الفرع `main` يُطلق نشرًا جديدًا تلقائيًا في Vercel. وأي فرع آخر يحصل على رابط معاينة مستقل قبل الدمج.

### ربط نطاق خاص (اختياري)

Vercel → المشروع → **Settings → Domains** → أضيفي النطاق واتبعي تعليمات DNS، ثم حدّثي `NEXT_PUBLIC_SITE_URL` وأعيدي النشر.

## تحديث البيانات

كل المحتوى في مجلد `data/` منفصل عن الواجهة:

| الملف | المحتوى |
|---|---|
| `data/regions.json` | المناطق: المقر، السكان، المساحة، المحافظات، الأقسام وفقراتها ومصادرها، الجامعات |
| `data/heritage.json` | مواقع التراث العالمي وعناصر التراث غير المادي |
| `data/sources.json` | المصادر: العنوان، الجهة، الرابط، السنة المرجعية، تاريخ آخر تحقق |
| `data/geo/sa-regions.geojson.json` | حدود المناطق |
| `data/geo/context.json` | اليابسة المحيطة والمعالم الطبيعية وأسماء البحار |

قواعد إلزامية يفرضها فحص البيانات:

- كل فقرة في أقسام المناطق يجب أن تحمل مصدرًا واحدًا على الأقل من `sources.json`.
- مجموع سكان المناطق يجب أن يطابق إجمالي التعداد.
- كل منطقة يجب أن تكون لها حدود في ملف الخريطة.

بعد تعديل أي ملف بيانات على GitHub (حتى من واجهة الموقع مباشرة)، يعيد Vercel البناء والنشر تلقائيًا خلال دقيقة تقريبًا. التحديث دون إعادة بناء يتطلب قاعدة بيانات، وهو جزء من المرحلة الخامسة.

## الحدود الجغرافية — تنبيه مهم

الحدود الحالية مأخوذة من **Natural Earth 1:10m Admin 1** (ملكية عامة)، وهي **مرحلية** لأغراض العرض. المرجع الرسمي هو **الهيئة العامة للمساحة والمعلومات الجيومكانية** (geosa.gov.sa). عند الحصول على بيانات الهيئة وفق شروط استخدامها:

```bash
# ضعي الملف الخام في مجلد raw-geo/ (مستبعد من Git)، ثم عدّلي سكربت التحويل ليقرأ حقول الهيئة
node scripts/build-geo.mjs raw-geo/<الملف>.geojson
```

السكربت يتحقق من وجود 13 منطقة بالضبط، ويختصر الإحداثيات إلى 4 منازل عشرية.

طبقات السياق (اليابسة المحيطة، والربع الخالي، والنفود، وطويق، وجبال الحجاز وعسير، وتهامة، وسهل الأحساء، وأسماء البحار، والقمم) تُبنى بسكربت منفصل من ملفات Natural Earth الخام:

```bash
node scripts/build-context.mjs raw-geo/   # ينتج data/geo/context.json
```

## بنية المشروع

```
app/                     الصفحات (App Router)
  page.tsx               الرئيسية والأطلس
  regions/[id]/page.tsx  قالب صفحة المنطقة (13 صفحة ثابتة)
  heritage/ numbers/ search/ sources/ about/
components/              مكونات قابلة لإعادة الاستخدام
  AtlasMap.tsx           الأطلس التفاعلي في الصفحة الرئيسية (عميل)
  AtlasDefs.tsx          أنماط الصحارى والجبال والسهول والظلال
  RegionPlate.tsx        المنطقة منفردة بتضاريسها (خادم)
  Parapet.tsx            حافة الشُّرَف النجدية والفاصل الزخرفي
  PageHero.tsx           رأس الصفحات الداخلية
  RegionLocator.tsx      خريطة موقع ثابتة (خادم)
  SearchBox.tsx          البحث الفوري
  SourceRef.tsx          إحالات المصادر ووسم «بحاجة للتحقق»
lib/
  data.ts                قراءة البيانات والمؤشرات
  geo.ts                 حساب مسارات الخريطة وقت البناء (d3-geo)
  search.ts              فهرس البحث وتوحيد الكتابة العربية
data/                    المحتوى والمصادر والحدود
scripts/                 تحويل الحدود وفحص البيانات
```

التقنيات: Next.js 16 (App Router)، React 19، TypeScript، Tailwind CSS 4، Framer Motion، d3-geo. لا قاعدة بيانات ولا خدمات خارجية في هذه المرحلة.

## إمكانية الوصول والأداء

- اتجاه RTL صحيح، ورابط «تخطَّ إلى المحتوى».
- كل منطقة على الخريطة عنصر قابل للتركيز بلوحة المفاتيح، مع قائمة أزرار بديلة مرتبطة بالخريطة.
- تفضيل «تقليل الحركة» يلغي الانتقالات والحركة.
- كل الصفحات مولّدة مسبقًا (Static/SSG)، فتصل سريعة من شبكة Vercel.
- ترويسات أمان أساسية في `next.config.ts`.

لم يُجرَ بعد تدقيق WCAG 2.2 AA كامل بأدوات متخصصة؛ هذا ضمن المرحلة الخامسة.

## ما يحتاج إكمالًا أو تحققًا

- عدد الجامعات: لم يُعتمد رقم لأن التعريف (حكومية/أهلية/كلتاهما) يغيّره؛ المصدر المعتمد قوائم وزارة التعليم.
- المساحات وأعداد المحافظات تقريبية من سعوديبيديا، وعدد محافظات مكة المكرمة غير مذكور فيها.
- منطقة موقعي «عروق بني معارض» و«الفاو» الإدارية لا تذكرها صفحات اليونسكو؛ تُعرض بوسم «بحاجة للتحقق».
- إحداثيات مقر إمارة الباحة غير متوفرة في مصدر النقاط المستخدم.
- لا صور في هذه المرحلة: لم تُدرج أي صورة قبل التحقق من ترخيصها.
- العناوين العربية لعناصر اليونسكو ترجمة عمل، والمرجع هو العنوان الإنجليزي الرسمي.
